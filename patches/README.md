# LoopForge 微能科技适配补丁集

这组补丁是微能科技在腾讯 LoopForge 0.3.8（上游提交 `d85f605`）基础上的落地适配，
用于跟进上游新版本时重放/rebase。

| 补丁 | 内容 |
| --- | --- |
| `0001-*` | 工蜂/GitLab 适配：内部 GitLab 端点、凭据校验、MR 链路、MCP 双写、CLI 参数探测 |
| `0002-*` | 审批与审计：审批人过滤、驳回留痕、运行事件可见、节点反馈展示 |
| `0003-*` | 执行编排：个人执行机目标、客户线分支、SSP 分支命名、执行机自检 |
| `0004-*` | 稳定性：僵尸检测、任务租约、产物上限、领取查询加固、MySQL 参数 |
| `0005-*` | 其余适配收尾 |

重放方式：

```bash
git checkout -b my-adaptation <upstream-version>
git am patches/*.patch
```

注意：补丁不含任何内部令牌、地址以外的客户敏感信息；内部地址请按部署环境替换。
